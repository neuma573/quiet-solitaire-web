iOS 앱의 기록과 Game Center

게임 설정, 플레이 통계와 XP는 기기에 저장됩니다. Game Center에 로그인해도 이 기록이 다른 기기로 동기화되거나 웹 리더보드로 옮겨지지 않습니다. 진행 중인 카드 배치와 되돌리기 이력의 앱 재시작 후 복원은 현재 제공하지 않습니다.

Game Center 연결은 Apple이 제공합니다. 연결되지 않아도 게임을 즐길 수 있습니다. Game Center 계정이나 로그인 문제는 기기의 Game Center 설정을 확인해 주세요. 지원 메일로 Apple 계정 비밀번호를 보내지 마세요.

기록 문제가 있다면 먼저 문의해 주세요. 앱을 삭제하거나 데이터를 지우면 기기의 기록을 잃을 수 있습니다.

실험용 웹 게임의 리더보드

웹 게스트와 XP는 iOS Game Center와 별개입니다. 같은 브라우저의 쿠키를 통해 게스트에 접근하며, 다른 기기나 브라우저에서 자동으로 복원되지 않습니다.

웹 게임의 나의 모든 기록 삭제는 확인 후 해당 게스트의 서버 리더보드 ID, 닉네임, XP와 기록을 삭제합니다. 기기의 게임 데이터·로컬 통계는 지우지 않습니다. 쿠키만 지우면 서버 기록은 삭제되지 않은 채 접근을 잃을 수 있습니다.

iOS records and Game Center

Game settings, statistics and XP are stored on your device. Signing in to Game Center does not sync these records to another device or the web leaderboard. Restoring an in-progress board and undo history after restarting the app is not currently supported.

Apple provides Game Center. You can play without connecting to it. For account or sign-in issues, check your device's Game Center settings. Never send your Apple Account password to support.

If you have a records problem, contact support before deleting the app or clearing its data, as you may lose local records.

Experimental web leaderboard

Web guest profiles and XP are separate from iOS Game Center. A browser cookie gives access to your guest profile; it does not automatically transfer to another device or browser.

The web game's 나의 모든 기록 삭제 control deletes that guest's server leaderboard ID, nickname, XP and records after confirmation. It does not erase device game data or local statistics. Clearing cookies alone can leave the server records in place while losing access to them.
